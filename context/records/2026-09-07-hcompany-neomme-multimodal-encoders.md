## 핵심 요약
> H Company가 260M·800M 크기의 단일 타워 양방향 멀티모달 인코더 'NeoMME'를 Apache 2.0으로 공개했다. 사전학습 비전 타워와 생성용 디코더를 걷어내고 마스크 디퓨전으로 밑바닥부터 학습해, 260M 모델이 ViDoRe v3에서 3.75B ColQwen2.5와 0.002포인트 차이의 검색 정확도를 냈다.

## 번역 (한국어)
오늘날 실무에서 쓰이는 시각 문서 검색기 대부분은 '물려받은' 모델이다. ColPali와 그 후속 모델들은 생성형 비전-언어 모델을 인코더로 재활용한 것으로, 여전히 별도 사전학습 비전 타워와 정작 토큰을 생성하지 않는 인과 디코더를 짊어지고 있다. 표현(representation)만 필요한 작업에 파라미터와 연산 낭비라는 지적이 나온 배경이다.

H Company의 NeoMME는 이 두 가지를 모두 제거한 260M·800M 양방향 인코더 패밀리다. 하나의 트랜스포머가 다국어 텍스트 토큰과 32×32 RGB 이미지 패치를 같은 레이어로 처리하며, 무작위 초기화부터 학습됐다. 텍스트는 ALBERT 스타일 인자화 임베딩(256차원 룩업)으로, 이미지는 스크래치 학습 2계층 MLP로 투입된다. 16,384 토큰 컨텍스트로 4K UHD 이미지 2장을 패칭 후 수용할 수 있고, 대부분 층은 대칭 슬라이딩 윈도우 어텐션, 6층마다 전역 어텐션을 쓴다. 13만 1,072 어휘의 신규 BPE 토크나이저는 14개 언어에서 ModernBERT 대비 44.4% 적은 토큰을 발행한다.

사전학습은 텍스트(선택적으로 이미지 패치 조건) 위한 이산 마스크 디퓨전 방식이다. 텍스트 구간은 0~1의 균등한 손상률, 멀티모달 구간은 0.30~1의 손상률을 적용해 '언어만으로 통과'하는 지름길을 차단했다. 교차 모달 소거 실험에서 90% 마스킹 시 보이는 페이지 패치가 마스크 토큰 정확도를 260M 기준 38.4포인트, 800M 기준 40.5포인트 끌어올려 실제로 페이지를 읽고 있음을 확인했다. 각 학습 실행은 16·32장의 H100에서 약 5,240억 개의 패킹된 입력 토큰을 처리했다.

검색 튜닝판인 NeoMME-Retriever는 하나의 백본 위에 밀도(dense) 헤드와 후기상호작용(late-interaction) 헤드를 공동 학습해 한 번의 순전파로 둘 다 반환한다. ViDoRe v3에서 260M은 0.523, 800M는 0.556 nDCG@10을 기록했는데, 260M 결과는 3.75B 파라미터의 ColQwen2.5-v0.2와 0.002 차이, 300M 미만 최고 모델 대비 26.1포인트 앞선다. 후기상호작용 인덱스의 고비용도 계층적 토큰 풀링+int8로 39.4×, 이진 문서까지 적용하면 255.5×(페이지당 6.0 kB)까지 압축하면서 각각 99.16%·95.19% 정확도를 유지한다. 배포성도 검증됐다: L40S 한 장에서 초당 51.3페이지 인덱싱(ColModernVBERT의 1.97배), CPU 전용 호스트에서도 쿼리 인코딩 78.3ms. 단, BEIR-15 텍스트 검색은 149M LateOn(0.5722)에 뒤처지며 저자들은 감독 규모 차이(약 43만 vs 6.6억 대비 사례)를 원인으로 꼽았다.

## 왜 중요한가?
문서 검색·RAG 시스템이 '생성 모델을 인코더로 재활용'하는 관행에 정면으로 도전한 발표다. 260M 크기로 3.75B급 검색 정확도에 근접하면, 기업들이 고가 GPU 없이도 문서 검색 인덱싱을 자체 서버에서 돌릴 수 있다는 뜻이다. Apache 2.0과 Hugging Face 당일 지원까지 갖춰져, 문서가 많은 한국 기업의 온프레미스 RAG 구축 비용을 크게 낮출 수 있는 실용적 선택지가 될 수 있다.

## 심층 분석

### 기술 의미
'비전 타워 제거'는 멀티모달 아키텍처에서 표현 학습과 생성 능력을 분리하려는 설계 철학의 전환점이다. 마스크 디퓨전 사전학습으로 밑바닥부터 학습하면서도 패치-텍스트 융합이 작동한다는 교차 모달 소거 결과(90% 마스킹에서 +38.4포인트)는 범용 VLM 의존 없이 문서 이해 인코더를 만들 수 있음을 실증했다. 255× 인덱스 압축(이진 문서 벡터)은 후기상호작용 방식의 최대 약점인 저장 비용을 사실상 해소한 것으로, 토큰 풀링+양자화 조합이 nDCG 95% 이상을 유지한다는 점이 실무 적용의 열쇠다. 반면 텍스트 검색 열세는 아키텍처 문제가 아니라 감독 데이터 규모 문제임을 저자들이 명시해, 과제의 성격을 정확히 진단했다는 점도 신뢰를 높인다.

### 업계 영향
소형 인코더가 대형 리트리버의 정확도를 따라잡으면 RAG 파이프라인의 비용 구조가 인코더 쪽으로 재편될 수 있다. 특히 문서 AI(계약서·논문·기술문서 검색) 시장에서 '거대 생성 모델 재활용'이 필수가 아니라는 반례가 생긴 셈이라, 검색 특화 소형 모델 생태계가 활성화될 것이다. ColPali 계열의 사실상 표준에 도전하는 오픈소스 대안의 등장은 벤더 락인 없이 온프레미스 문서 검색을 구축하려는 금융·의료·공공 수요에 직접 부합한다. Hugging Face Transformers 당일 지원은 채택 장벽을 낮춰 생태계 편입 속도를 높일 요소다.
