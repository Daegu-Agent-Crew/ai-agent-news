### 2. 월마트, AI 에이전트용 MCP 'Agent Gateway'·Agent Profiles 공개 — 아마존이 막을 때 문을 열다 ⭐⭐

**출처**: [TechCrunch](../records/2026-10-22-walmart-agent-gateway-mcp-agentic-commerce.md) (10/21 발행·10/22 수집, major-media, 교차 확인 1)

- **내용**: 승인된 에이전트가 MCP로 월마트·Sam's Club 재고 검색·구매 대행 — Agent Gateway. 다음 달 Agent Profiles: 에이전트별 전용 프로필 승인(본인 구매와 분리 조회), 거래마다 승인 요구 또는 설정한 지출 한도 내 허용("신용카드 가족 추가 사용자" 비유). 에이전트 전용 약관 — 의도대로 동작 안 해도 반품 절차 적용, 쇼핑객 의도 초과 행동·결제 정보 접근 불가, 필요한 정보만 접근, 약관 위반 에이전트 차단. 고객이 개인정보·구매 이력을 에이전트에 직접 공유하지 않는 구조. 이미 Meta Muse 제휴·ChatGPT·Gemini 통합 운영 중
- **①축 배치**: 51차가 확인한 '접근의 시장화'(제휴·라이선스·소송의 가격표)에 대한 유통 최상위권의 반대 답안 — 차단(아마존·여행·예약 사이트) 대 문 개방+권한·한도·약관 설계. MCP가 개발자 도구를 넘어 대형 유통의 커머스 인터페이스로 채택된 첫 사례. 45차 Meta·Walmart·Stripe 에이전트-기업 통신 오픈 표준 착수(숙제 159)의 첫 실물 후보. 에이전트 신원(프로필)·지출 한도·반품 보장이 소비자 계정 수준에서 한 세트로 — 87 플립카트 결제·120 Gemini 통합 에이전트·52 권한 위임의 소매 착지. 결제 정보 접근 차단은 결제 실행을 플랫폼 측에 남겨 에이전트 탈취 피해를 줄이는 구조
- **관전(숙제 신설 169)**: ① Agent Gateway 가동 후 실제 에이전트 거래량·차단 사례 ② Agent Profiles의 가족 추가 사용자 모델 실측(오남용·한도 우회) ③ 에이전트 전용 약관의 업계 표준화(아마존·타 유통의 응답) ④ 45차 오픈 표준 그룹과의 관계(개별 MCP vs 표준)

### 53차 업데이트 종합 분석: "양날의 실측과 문의 제3 가격"

1. **발견의 양날(1번)**: AI가 진짜 치명 결함을 찾는 능력이 실측되는 순간, 같은 능력의 악용 난이도 하락이 동시 경고됨 — '방어막=악용 난이도' 공식이 무너지며 보안이 능력 경쟁으로. 43차 'AI 슬롯 제보'와 진짜 발견이 같은 기술의 양면임이 확인되며 검증 계층(숙제 106)의 가치 상승
2. **문의 양극(2번)**: 최대 유통 2사가 정반대 — 접근이 성능이 아니라 '어느 문이 열렸는가'로 결정되는 시대의 첫 정면 대비. 월마트의 반품 보장·지출 한도는 소비자 에이전트 신뢰의 첫 실무 설계로, 51차 가격표 시장에 '개방+통제'라는 제3 가격을 제시
