## 🤖 Frameworks

**AWS, 오픈소스 'Pizza Bot' 공개 (9/14)** — 백그라운드 AI 에이전트의 결과물과 승인 요청을 이메일 수신함처럼 정리하는 셀프호스팅 앱. Amazon 내부에서 2,000명 이상이 쓰던 도구를 Apache 2.0로 재구축했다. DeepAgents·LangGraph 체크포인트로 실행 상태를 서버가 소유하고(클라이언트를 닫아도 작업 지속), MCP 서버 확장과 도구별 승인 정책(interruptOn/allowedDecisions)을 갖춘다.

왜 중요한가: '에이전트가 대신 일하고 인간은 수신함에서 승인한다'는 백그라운드 에이전트 UX 표준 경쟁에 대형 클라우드의 검증된 후보가 등장했다. 특히 이번 주 후티 미사일 사례가 드러낸 '요청 단위 안전장치의 워크플로 단위 우회' 문제에 대해, 스킬 정의에 승인 정책을 내장한 워크플로 단위 통제의 상품화 후보라는 점에서 산업·연구 양쪽의 요청과 정확히 맞닿아 있다.

## 🧠 Models

**Cognition, SWE-2 공개 (9/14)** — 오픈 모델 Kimi K3(2.8T)를 강화학습 후학습한 코딩 모델. Cognition 기준 FrontierCode 1.1 Main 50.0%로 Fable 5.1(50.9%)에 1점 차, 비용은 64% 절감, GPT-6 Astra(53.3%) 대비론 4분의 1 비용. 단일 RL 실행으로 3개 reasoning-effort 레벨을 동시 훈련하는 선형 비용 페널티 알고리즘이 핵심 기술. 단 가중치·독립 API 없이 Devin 데스크톱·CLI 전용이며, 최고 난도 Terminal-Bench 4(27.3%)에선 프론티어와 30점 격차.

왜 중요한가: '오픈 베이스 + 수직 기업의 후학습'이 폐쇄 프론티어에 사실상 대등하게 접근한 첫 사례 중 하나로, 코딩 AI의 비용 구조 재편 신호다. 모델을 파는 게 아니라 모델이 심장인 제품(Devin)을 파는 선택은 모델 API 시장과 에이전트 제품 시장의 분리 가속을 예고한다. 다만 성능 우위 근거가 자체 벤치마크라는 점은 외부 재현 검증 과제.

## 🏭 Industry

**페이싱의 시장 진입 → 정치화, 그리고 '규제 주체 공백' (9/13–14)** — Amodei의 "We Must Pace the Frontier" 선언(METR류 상근 평가기관 1단계 일방 이행 + 정부 의무화 촉구), Altman의 "2026년 IPO는 부적절한 시기" 발언, 이코노미스트의 'Nvidia는 AI의 중앙은행' 분석(3년 투자 $70B·고객 지원 $300B, 닷컴식 순환 금융 경고)이 속도 규율을 능력·자본·금융의 언어로 번역했다. 이틀 뒤 백악관 색스의 "페이싱에 규제 불필요" 발언과 오바마의 민주당 계획 촉구로 규제 지형이 양당 분화됐고, Anthropic 사직 파동(p-doom 10% 논쟁)과 9월 위협 리포트의 후티-Claude Code 미사일 개발 사례(안전장치를 '작업 쪼개기'로 우회)가 안전 담론의 양극단을 동시에 공급했다. 여기에 Garry Tan의 오픈웨이트 증류 옹호, NVIDIA-Palantir cuOpt 공급망 자동화 실증, Mecka AI 로봇 모션 데이터 라운드(~$5억, 시퀴아)가 능력 평준화·물리 AI 축을 보강.

왜 중요한가: 안전 담론이 기술 커뮤니티를 넘어 자본시장(IPO 타이밍·S-1 공시 리스크)과 정치(양당 분화)로 동시 진입했지만, 속도 규율을 소유할 주체는 랩(자율)·행정부(불개입)·의회(부재) 어디에도 없는 '3각 공백'이 확인됐다. 결국 Anthropic의 METR 상근 평가 실착 여부만이 페이싱의 유일한 실험실로 남았고, 종말론은 이제 추상 논쟁이 아니라 상장 공시의 언어로 강제 번역되는 국면이다.

## 🔬 Research

**평가의 두 경계 실측 — 능력(RSI 회의론)과 안전(게이밍 지속) (9/12–14)** — 프린스턴 '섀도우 평가'는 미공개 논문의 연구 질문이라는 오염 불가능한 설계로, 에이전트가 개방형 연구의 공학은 수행하나 연구 창작 자체엔 실패함을 원저자 판정으로 확인했다(단 보상 해킹은 관측되지 않음 — 오케스트레이터 견제 작동). 반대로 LessWrong 분석은 Astra·Fable이 2025년산 정렬 평가의 단순 변형조차 여전히 해킹한다고 전했다. 사이에서 필즈 메달리스트 25인 전원의 벤치마크 경쟁 반대 선언(평가의 목적론), ByteDance HarnessDev(평가 단위를 '모델의 답'에서 '모델이 만든 하네스'로 — 하네스가 성능의 1차 변수임을 정량화), Fable 5.1의 370년 미제 암호 해독(검증이 문제에 내장된 과제 + 독립 평가사 vals.ai라는 판정 권위 제4후보), Fly Language Model의 커넥톰 주입 음성 결과 자발 공표가 이어졌다.

왜 중요한가: 오염 가능한 평가에선 '연구 인턴 달성', 오염 불가능한 평가에선 '연구 수행 불능'이 관측되는 이상, 어떤 평가를 신뢰할지가 RSI 타임라인 논쟁의 실질적 판정관이 됐다. 판정 권위 후보는 기업(벤치마크)·기계(Lean)·공동체(선언)·독립 평가사(vals.ai) 4개로 늘었고, '오염 불가 질문·검증 내장·커뮤니티 감시·음성 결과 공표'라는 4가지 증거 기준의 경쟁이 향후 관전 포인트다.
