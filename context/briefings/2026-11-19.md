## Frameworks — 멀티에이전트 검증 구조 확산
- **Perplexity Computer Multiagent**: 최대 16개 에이전트가 병렬 작업·증거 공유·교차 검증. 리드 에이전트가 이종 프론티어 모델 팀 지휘. 공개 벤치마크는 아직 없음.

**왜 중요한가?** 여러 AI가 팀을 이뤄 서로 검증하는 방식이 일반 사용자 상품으로 확산 중이다. 단순 위임이 아닌 이의 제기·공유 파일 조율 구조가 등장했다.
**인사이트**: Kimi 300 서브에이전트·Manus 등과 함께 '에이전트 동원 규모'가 경쟁 축으로 자리 잡았으나, 정확도 검증 데이터 부재는 빈칸으로 남아 있다. (→ 분석)

## Tools — 에이전트 도구가 플랫폼 제작 수단이 되다

- **Proton Lumo Desktop**: 프라이버시 중심 데스크톱 에이전트, Windows·macOS·Linux.

**왜 중요한가?** 플랫폼이 자체 개발툴 대신 개발자의 에이전트 환경으로 찾아가는 '플랫폼→에이전트' 전략 첫 사례군이 형성됐다. 개인 비서 AI가 유료 상품이 아닌 기본 서비스로 내려오는 전환점이기도 하다.
**인사이트**: 개인 데이터 전체를 결합한 에이전트 실행이 대규모 배포 단계에 들어가며, 권한·프라이버시 설계가 도구 선택의 1차 기준으로 부상한다. (→ 분석)

## Industry — Anthropic IPO와 에이전틱 웹 경제학
- **Anthropic IPO $83 책정** (⭐⭐⭐⭐): 완전희석 기업가치 약 $1.5T, 나스닥 'ANT'. 아마존 ~15% + 구글 ~14% ≈ 29%. 전략투자자단 $26B(구글·엔비디아 각 $10B).
- **나델라 에이전틱 웹 발언**: 광고 노출 수익모델이 CPC·거래 기반으로 재편될 것. "에이전트를 받아들이지 않으면 다른 누군가가 받아들일 것."

**왜 중요한가?** AI 역사상 최대 규모 상장이 후속 기업 밸류에이션 기준점이 되고, 빅테크 지분 구조가 컴퓨트 공급망과 모델 개발 속도를 규정한다. 에이전트 트래픽 시대의 웹 수익모델 재편 논의도 현실화했다.
**인사이트**: $26B 전략투자는 프론티어 AI 조달이 '반도체·클라우드 밸류체인 결속' 방식으로 진화했음을 보여준다. 나델라의 프레임은 Copilot 생태계에 유리한 경쟁사 발언으로도 읽어야 한다. (→ 분석)
