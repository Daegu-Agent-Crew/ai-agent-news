## 🔧 Tools — Decisions API 공개 베타, 판단의 단가가 드러나다

OpenAI Decisions API가 공개 베타로 열렸다. 텍스트·이미지를 넣으면 산문이 아닌 타입형 답변(확률·선택·점수)을 돌려주고, Responses API 대비 약 10배 빠르며(결정 1건 약 150ms) gpt-6-luna 기준 입력 100만 토큰당 $0.10에 출력 과금이 없다. 정확도·보정 데이터는 미공개라 도입자가 직접 임계값을 보정해야 하는 부담과, TypeSafe Jev($0.042)보다 2.4배 비싼 가격은 엔터프라이즈 컴플라이언스(ZDR·HIPAA)·이미지 입력으로 메우는 구도다. 전날 Goodfire의 내부 활성값 모니터($51/1,500세션)와 함께, 에이전트 운영의 판단·감시 비용을 낮추는 도구가 도구 생태의 새 축으로 올라왔다.

## 🔬 Research — '실수에서 되돌아오는' 에이전트의 학습법

창구 내 유일한 연구 기록은 NVIDIA·프린스턴·메릴랜드의 PivotOPD(10/09, 전일 브리핑 상세). 실패한 실행의 59%가 초반 '결정적 실수'에서 비롯되고 이후 18~21턴을 회복 없이 낭비한다는 정량 분석 위에, 교사 모델의 실수 지목 + 예방 증류(reverse KL) + 회복 증류(forward KL)를 결합해 회복률을 20.3%→72.7%로 끌어올렸다. 학습 레시피만 바꾸므로 추론 비용이 늘지 않는다는 점이 배포 부담 없는 신뢰성 개선이라는 실무 가치다. 오래 도는 에이전트의 신뢰성이 '실수 안 하기'에서 '실수에서 되돌아오기'로 재정의되고 있다.
