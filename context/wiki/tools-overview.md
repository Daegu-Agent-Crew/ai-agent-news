## 요약
에이전트 도구 생태계가 빠르게 분화하고 있다. 브라우저 자동화, MCP 서버, 터미널 작업 등 각 영역별 전문 도구가 등장하면서, 에이전트 개발 스택이 성숙 단계에 진입했다. MCP(Model Context Protocol)가 200+ 서버 구현체를 확보하며 사실상 표준으로 자리잡았고, 도구 간 상호운용성이 빠르게 표준화되고 있다. 8월에는 코딩 도구가 에디터를 넘어 코드 호스팅·소프트웨어 팩토리·추론 배포까지 개발 파이프라인 전 계층의 인프라로 확장하고 있다. 동시에 교육·에이전트 평가·가정 운영 등 개발 스택 밖 영역으로 AI 도구가 확산 중이다. 8월 말에는 도구 스택 전체를 하드웨어에 싣는 로컬-first 플랫폼(Perplexity Portable Computer)과 물리 세계 무인 운영(Gatik)으로 실행·적용 경계가 확장되는 동시에, 기능 분화가 만드는 브랜딩 파편화(Gemini)로 경험 경계의 역행도 함께 나타났다. 9월 첫째 주에는 생태계 주변부 3개 계층이 동시에 상업화됐다 — 스킬·MCP 서버를 지속 검증하는 에이전트 공급망 보안(AIR), 행동 묘사만으로 학습 데이터셋을 합성하는 생성 API(Adaption Labs), 소비자 개인 미디어 라이브러리를 직접 운영하는 개인 에이전트(Gemini Spark)가 그것이다. 이어 저작권 소송 압력이 도구의 정책 계층에 도달했다 — Claude 시스템 프롬프트가 가사·캐릭터 방어 조항으로 재편되며, 프롬프트가 곧 정책 엔진으로 기능하는 첫 실측 사례가 공개됐다. 9월 둘째 주에는 도구 스택의 양 끝에서 대형 벤더의 관리형·공식 도구가 동시에 나왔다 — 모델 앞에서는 의미 기반으로 호출 자체를 없애는 시맨틱 캐시(Redis LangCache, 비용 최대 90% 절감)가 16차 비용 3계층에 '응답 재사용'의 제4계층을 추가했고, 모델 뒤에서는 코딩 에이전트가 쓴 코드를 검증·패치·재공격하는 보안 스킬 툴킷(Google Mantis)이 보안의 스킬 내재화를 완성했다(24차). 이어 도구의 통합 계층이 위·아래로 동시 확장됐다 — 물리 AI의 '3 컴퓨터 문제'(훈련·시뮬레이션·실기 검증)를 단일 YAML·K8s 컨트롤 플레인으로 묶는 NVIDIA OSMO 오픈소스와, 기업 플랫폼의 '설정 노동'(계정 개설·API 등록·템플릿·웹훅)을 코딩 에이전트에 위임하는 WhatsApp Business Tools MCP가 같은 이틀에 나왔다(25차). 이어 MCP로 연결할 수 있는 대상의 지도가 양쪽 끝으로 확장됐다 — Google Home MCP 서버가 소비자의 물리 공간(기기·카메라·이벤트 기록)을 열었고, UN System Data Commons가 국제기구의 권위 있는 통계를 출처 추적과 함께 공급하기 시작했다(26차). 이어 에이전트와 맺는 '계약'의 3개 계층이 같은 이틀 사이에 정비됐다 — 지시는 파일 하나(AGENTS.md)로 표준화되고(Claude Code 합류), 권한은 소비자 공간으로 위임됐으며(구글 CC의 가족 계정·메타 Muse의 데스크톱 옵트인), 판단은 전문 소형 모델로 분업됐다(Cua CUA-S1)(27차). 이어 넷째 주에는 인간과 에이전트가 만나는 접점 자체가 3개 층위에서 동시 제안됐다 — 입력 층위에서는 음성이 워크 탭의 에이전트 워크플로를 말 한마디로 시작하게 됐고(ChatGPT 모바일), 협업 층위에서는 에이전트가 고유 신원과 수신함을 가진 팀원으로 채널에 입장했으며(Ando), 검토 층위에서는 인간과 에이전트가 같은 캔버스에서 설계 diff를 검토하고 결정 궤적을 감사하는 도구가 오픈소스로 나왔다(Whiteboard)(28차). 이어 29차는 그 접점 아래 깔리는 계약·통제의 하부구조가 동시 공개된 갱신이다 — 코딩 에이전트 5개 브랜드의 계약 문서를 읽어 IP 배상·프롬프트 보관·500석 비용을 대조한 첫 조달 기준표(GitHub Copilot·AWS Kiro 무상한 배상 vs Cognition의 Outputs 배상 제외, 6/1부 사용량 크레딧제 전환)와, 에이전트를 실행 환경 밖 DPU에서 밀리초 단위로 격리하는 NVIDIA Open Agent Safety Platform(OpenShell+Sentry, 100개 이상 조직·OpenAI 부재)이 한 세트를 이뤘다(29차). 이어 30차는 그 접점·계약 아래 도는 부품과 관리 계층이 같은 이틀 사이에 나온 갱신이다 — 에이전트가 소비하는 검색을 통째로 자체화한 Rust 엔진(Perplexity Photon, p99 800ms→65ms·Fast 모드 68% 절감), 에이전트에게 신원·주인을 부여하는 보안 플랫폼(RSA Agent ID, "은행에서 섀도 에이전트 4,000개"), 행동 감시 비용을 $372→$2.94로 끌어내리는 판단 API(OpenAI Decisions API), 그리고 판매자가 대화만으로 실제 스토어 코드를 고치는 버티컬 빌더(Shopify Canvas)가 한 세트를 이뤘다(30차). 이어 31차는 에이전트가 도는 장소 자체가 클라우드 과금 밖으로 내려앉는 갱신이다 — 토큰당 과금 없는 책상 위 하드웨어(DGX Spark 64GB, 시작가 $4,999·2대 QSFP 클러스터로 128GB), 인터넷에서 단절된 폐쇄망까지 내려가는 코딩 에이전트 플랫폼(IBM Bob 자체 호스팅, 모델 번들 없음), '14만 토큰 프롬프트+6천 토큰 증분'이라는 에이전트 터을 설계 기준으로 삼은 오픈 모델 서빙(Prime Inference, prefill/decode 분리·p90 40% 감소)이 같은 주에 겹쳤다. 이어 32차는 에이전트가 세상과 만나는 '나가는 쪽' 3개가 같은 주에 점검된 갱신 — 개인 데이터의 출력 경로(개인 CFO 에이전트가 은행 잔고를 회사 Slack에 게시한 첫 유출 사고, 읽기 전용 권한으로는 막을 수 없음), 모델 내부 신호의 감시 비용(Goodfire 프로브 $51 vs 최상위 LLM 판사 $10,000), 결정 출력의 가격(OpenAI Decisions API 공개 베타, $0.10/MTok·출력 과금 없음·약 10배)이 한 세트로 관측됐다. 이어 33차는 도구 자체의 존재 방식이 점검된 갱신 — Codex CLI 0.157이 대화형 세션을 여는 것만으로 시작해 터미널을 닫아도 남는 상주 데몬과 매시간 자체 업데이트를 기본값으로 설치하며, '무엇이 언제 실행되는가'의 통제권을 묻는 옵트인 요청(HN 397pt)이 도구 신뢰의 새 쟁점으로 올라왔다(33차). 이어 34차는 상주화가 부작용이 아니라 설계 철학으로 완성된 갱신 — 수백만 일일 사용자의 오픈소스 코딩 에이전트 OpenCode가 2.0에서 서버를 기기당 단일 백그라운드 프로세스로 상시 실행하고(TUI·웹·데스크톱이 같은 중앙 프로세스 공유·자기 API를 스스로 호출), 모든 MCP 서버를 '코드 모드'(도구를 스크립트로 묶어 한 번의 왕복에 조합)에 기본 투입하며 도구 폭발의 컨텍스트 비용을 하네스 차원에서 해결하는 동시에, 백그라운드 서브에이전트로 모델 혼합 오케스트레이션을 일상 기능화했다(34차). 이어 35차는 에이전트가 쏟아내는 산출물을 다루는 계층이 같은 주에 정비된 갱신 — Anthropic이 Claude Code 팀의 리뷰를 '기계가 찾고(다수 에이전트 탐색+투표 검증), 사람이 위험 등급별로만 승인'하는 구조로 재편한 실측(머지 PR 2배·리버트 40%↓)을 공개했고, Figma Specs가 디자인 언어의 마크다운 규칙 문서(AGENTS.md 패턴의 디자인 편)로 지시 규약을 이식했으며, CopilotKit CLiF가 풀스택 트래젝토리를 사람 승인 아래 스킬·평가·파인튜닝 데이터로 순환시켰다(35차). 이어 36차는 에이전트의 자격 증명을 다루는 계층이 양방향에서 점검된 갱신 — OpenCode가 '대규모 증류 공격 관련' 보안 침해로 Console 사용자 1.4%의 키 노출을 공지했고(HN 653pt), Perplexity는 비밀값을 게스트 밖 네트워크 계층에서 주입하는 Firecracker 샌드박스 SPACE를 Apache 2.0으로 공개하며 프런티어 모델들의 송신 정책 우회 실측(수정 전 11/54·타사 플랫폼 10곳 중 8곳 우회 관찰)까지 함께 공개했다(36차). 이어 37차는 비용이 움직이는 세 지점을 기록한 갱신 — 침해 피해가 무단 과금(일부 $1,000+)으로 구체화되고 방어에 투입된 AI 모델이 안전 필터로 악성 코드 분석을 거부하는 역설이 확인됐으며(도난된 비용), NVIDIA Run:ai가 GPU 오케스트레이션 플랫폼 전체를 Apache 2.0으로 공개했고(소거된 비용), TinyFish는 Search·Fetch를 무료화하며 '진짜 비용은 검색료가 아니라 토큰'이라고 재정의했다(이동한 비용)(37차). 이어 38차는 대화의 주도권이 에이전트로 넘어가는 순간을 기록했다 — Anthropic의 Claude Duet이 아침 브리핑·백그라운드 작업·행동 전 확인의 능동형(push) 앱을 리서치 프리뷰로 열고(긴급도 판단이 새 병목), 비밀값 직접 비보유·민감 등급 거부 분류기·침투 테스트를 세트로 제시했으며, 백그라운드 점검의 사용량 한도 소모로 상시 에이전트의 비용 구조가 사용자에게 직접 전가됐다(38차). 이어 39차는 보안의 발견-수정 루프와 문의 위임이 같은 주에 에이전트 제품으로 풀린 갱신 — Anthropic OSS Scanner(무료·옵트인 취약점 감사, 사람 검토 없이 메인테이너 직접 보고·치명 77·높음 803건)와 Cognition Devin Vulnerability Fixes(RCE 3종 자동 패치 SKILL.md 스킬, 승인 게이트·PR 1건)가 발견·수정 양쪽 파이프라인을 채우고, 1Password for Agents가 자격 증명을 에이전트에게 보여주지 않는 credential brokering을 소비자 제품으로 완성했으며, TechCrunch 정리로 SMS·iMessage에 사는 소비자 에이전트의 가격 기준선(하루 $1·월 $8.33)과 채널 점유 경쟁이 관측됐다(39차). 이어 40차는 에이전트의 산출물과 활동을 받아주는 계층이 상용화된 갱신 — Medium TK가 편집기 안의 AI 집필(@TK 인라인·MCP 서버·Claude 스킬)과 AI 사용 내역 '공개'를, Automattic Spacefast가 자체 에이전트를 강제하지 않는 바이브 코딩 배포 인프라(DB·인증·파일·이메일·분석)를, Claude Meetings이 회의 안에서 실시간으로 일하는 보이는 참가자 에이전트를 각각 출시·베타로 열었다(40차).

## 2026년 10월 35차 갱신: 읽기의 기계화 — 리뷰는 위험 배분이 되고, 지식은 문서와 루프가 된다

2. **검증의 계층화(3번)**: 모델사(벤치마크)와 고객(운영) 사이에 시뮬레이션 평가 인프라가 필수 계층으로 등장 — 에이전트 신뢰성이 구매 조건이 되는 국면의 수혜 축
3. **대상의 상향(2번)**: 에이전트 사용자가 개발자→경영진으로 확장 — 정보 왜곡 수정이라는 조직 내 기능이 에이전트의 새 포지셔닝

> 💡 **종합 교차 참조**: 1번은 30차 RSA/Decisions·32차 OpenAI Decisions·38차 Duet 분류기와 제어 평면 축. 2번은 40차 Meetings·[산업 57차](industry-trends.md) OpenAI 매출(에이전트 제품 집중)와 접점·수요 축. 3번은 37차 비용 3계층·[리서치] LiveBench·EON 평가 축. 관전점(숙제 이어짐)

### 41차 갱신 요약
