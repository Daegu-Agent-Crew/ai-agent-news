# 유명 캐릭터 분석 → 모아별 v2 설계

2026-11-15. 아래 관찰과 설계적 해석을 구분한다. 판매량·인기도의 인과관계를 실증한 연구가 아니다. 유명 캐릭터의 외형을 혼합하거나 고유 도상을 가져오지 않는다.

## 확인한 공식 자료
### 헬로키티
- 출처: https://www.sanrio.co.jp/characters/hellokitty/
- 관찰: 공식 소개에 밝고 친절한 성격, 쿠키 만들기·피아노 취미, 시인/피아니스트의 꿈, 가족·친구 관계가 명시된다. 사과 개수로 키와 몸무게를 설명한다.
- 설계적 해석: 짧게 말할 수 있는 설정과 소소한 일상은 캐릭터를 직업 표지 이상의 존재로 만든다.
- 적용: 세 친구에게 바람·취미·실수 습관을 부여한다. 리본·수염·특유의 얼굴 구성을 가져오지 않는다.

### 스누피
- 출처: https://www.peanuts.com/about/snoopy
- 관찰: 책 읽기/쓰기, 상상 놀이, 비행사·Joe Cool 같은 역할 놀이가 소개된다. 공식 인용은 성공과 실패, 재난과 영웅을 오갈 수 있는 인물로 설명한다.
- 설계적 해석: 고정된 정체성 안에서 다양한 상황과 감정을 연기할 수 있어야 시리즈를 계속할 수 있다.
- 적용: 고정 외형은 유지하고 감정·자세·실험 도구를 바꾼다. 개 실루엣·귀·개집·항공 복장 등 고유 도상은 사용하지 않는다.

### 우드스톡
- 출처: https://www.peanuts.com/about/woodstock
- 관찰: 비행에 서툴며 스누피와 친한 친구이고, 모험과 집에서 쉬는 것을 즐긴다고 소개한다.
- 설계적 해석: 작고 서툰 면과 친구와의 관계가 완벽한 마스코트보다 많은 장면을 만든다.
- 적용: 또록의 주저함, 누비의 과몰입, 모루의 성급함을 서로 보완한다. 노란 새·깃털·울음 표현은 차용하지 않는다.

## 기존 v1에서 관찰한 문제와 변경
- 세 캐릭터가 비슷한 키·둥근 덩어리·웃는 표정에 집중 → 둥근형/가로형/세로형, 서로 다른 감정과 자세로 분화.
- 역할과 소품은 있었지만 갈등·욕망이 약함 → 질문/실험/조건 확인으로 협력하되 각자 실수할 여지를 설계.
- 누비의 두 접힘이 동물 귀처럼 보임 → 한쪽 큰 접힘과 고리 꼬리로 재구성.
- 모델 시트에 어두운 주변 음영 → 밝고 균일한 바탕. 인물은 명료하게, 장면은 풍성하게.

## v2 검토 범위
- 생성 시트 육안 검토: 세 체형, 역할 색, 한글 이름, 감정 대비, 하단 공동 작업 장면을 확인.
- 정밀 치수/턴어라운드/32px 인지 사용자 테스트는 미실시. 작은 포즈의 표현 차이는 고정 모델 시트 추가 제작 시 정리할 대상.
- 유사성 법률 검토 또는 저작권 확보 완료를 의미하지 않는다.

## 접근 제한
웹 검색 도구는 403으로 실패. 위 세 공식 페이지는 직접 HTTP 조회로 본문을 확인했다. 시도했지만 접근 실패/차단된 Pokemon·San-X·일부 Sanrio URL은 근거로 사용하지 않았다.
