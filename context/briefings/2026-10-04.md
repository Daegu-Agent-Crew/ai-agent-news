**🧠 Models** — 무게의 주권, 인터페이스의 귀속
독일 Aleph Alpha가 총 78B·활성 3B·1M 컨텍스트 MoE 모델 Kolibri를 Apache 2.0로 전면 공개했다. 활성 3B로 4배 큰 모델과 맞먹는 성능을 주장하며 온프레미스 운영 비용을 낮추고, '주권'을 데이터 수집부터 평가까지 공급망 전체의 속성으로 제시한다 — 열세 벤치마크까지 공개한 투명성이 눈에 띈다. Microsoft MAI-Transcribe-2-Streaming은 첫 가설 ~100ms·AA 38개 모델 중 정확도 1위($0.54/시간)로, OpenAI Realtime 호환 규격을 택해 음성 인터페이스도 '규격은 표준·모델은 교체품' 구도에 편입됐다.

**🔧 Tools** — 클라우드 과금 밖의 세 가지 자리
IBM이 코딩 에이전트 플랫폼 Bob의 자체 호스팅·폐쇄망(air-gapped) 버전을 정식 출시했다. 은행·공공처럼 코드 한 줄도 밖으로 내보낼 수 없는 조직에 코딩 에이전트가 들어갈 길이 열렸고, 메인프레임 레거시 현대화라는 포지션이 GitLab·GitHub와 다른 지면을 만든다. Prime Intellect의 Prime Inference는 '14만 토큰 프롬프트+6천 토큰 증분'이라는 에이전트 턴을 설계 기준으로 삼은 오픈 모델 서빙 — prefill/decode 분리로 p90 지연 40% 감소, 내부 하루 1조 토큰 처리를 보고하며 폐쇄형 API 대체를 현실화한다(수치는 자체 보고).
