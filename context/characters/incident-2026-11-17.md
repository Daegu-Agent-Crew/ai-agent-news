# 캐릭터 외형 변형·조연화 원인과 조치

## 관찰한 증거
- 11/17 그림에 두몽 유사 인물은 있으나 리루의 귀/코핀의 고유 창문·더듬이가 기준 시트와 달라지고, 일반 사람/로봇이 뉴스 장면 주연을 차지했다. 사용자 요청에 따른 사건 조사이며 정기 품질 검수의 재도입이 아니다.
- 예약 작업의 기존 생성 명령은 `codex exec ... "$(cat ...prompt.txt)"`로 **--image가 없었다**. 캐릭터 시트는 뒤쪽의 “지원되면 제공” 지시에만 존재했다.
- 남아 있는 11/17 digest-prompt.txt는 세 이름과 짧은 외형 설명을 포함하지만 참조 이미지 경로가 없고, 두몽을 방청/구경 역할로 지정했다. 코핀은 작은 등불을 든 벌레로 축약되어 창문 등껍질과 정육면체 더듬이 설명이 누락됐다.
- 명세가 검사/연구자를 전면에 요구하고, 오래된 템플릿도 회사/모델의 캐릭터 의인화를 지시했다. 후행 캐릭터 규칙과 주연 배정이 충돌했다.
- sessions_search는 90초 시간 초과. 최종 이미지 도구 내부 요청을 복원하지 못했으므로 실제 참조 인자가 반드시 없었다고 단정하지 않는다. 확인된 원인은 **예약 실행 경로에서 참조 전달이 필수가 아니었고, 장면 기획도 캐릭터를 조연화했다는 것**이다.

## 변경
- scripts/generate_picturebook.py: 캐릭터 PNG/설정 파일을 필수로 읽고 codex --image 첨부. 실제 이미지 생성 도구에도 referenced_image_paths 전달을 명시. 요청 전문·참조 및 가이드 SHA256을 JSON 기록.
- 참조 파일 누락/PNG 아닌 파일이면 실행 전에 실패. 텍스트 전용 폴백 및 다른 세션 최신 파일 무작위 복사 경로 제거.
- 아침/저녁 예약 프롬프트를 공통 실행기 기반으로 교체. 틈새 탐사대 주연, 일반 인물 조연, 회사는 간판. 명세의 무대보다 캐릭터 기준 우선.
- 사후 육안/비전/OCR 검수와 품질 재생성은 계속 제외. 입력 계약 테스트와 파일/전송 확인만 유지.

## 검증과 한계
- unittest 4건 통과: 아침/저녁 참조 첨부 및 전체 설정 전달, 참조 누락 차단, 비PNG 차단, 출력 경로 이탈 차단.
- 오늘 남은 프롬프트를 넣은 dry-run: 참조 PNG 첨부 명령과 전체 가이드 포함 요청 생성 성공. 실제 이미지 생성은 하지 않음.
- --image는 생성 담당 Codex에 전달을 보장하며, 내부 이미지 도구가 그 참조를 실제 사용하는 것은 명시적 지시다. 이미지 도구 내부 인자를 강제하는 별도 API 래퍼를 구현했다고 주장하지 않는다.
- 오늘 발행 이미지를 교체하지 않았고 다음 예약 실행의 시각적 일관성은 아직 관찰하지 않았다. 외형의 완전한 동일성을 보장한다고 보고하지 않는다.
