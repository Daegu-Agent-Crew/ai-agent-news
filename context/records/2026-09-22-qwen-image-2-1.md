## 핵심 요약
> 알리바바의 Qwen 팀이 텍스트→이미지 생성과 이미지 편집을 하나의 체크포인트로 통합한 7B 오픈웨이트 모델 Qwen-Image-2.1을 공개했다. 2025년 8월의 20B 전작보다 1/3 크기로 줄면서 투명 RGBA 출력과 최대 10장 참조 편집을 네이티브로 지원하며, 자체 벤치마크에서 공개 모델 중 1위 점수를 기록했다고 팀이 발표했다.

## 번역 (한국어)

알리바바 Qwen 팀이 통합 텍스트→이미지 생성·이미지 편집 모델 Qwen-Image-2.1을 공개했다. 시각 생성 컴포넌트는 32개 싱글스트림 DiT 레이어에 7B 파라미터다. 하나의 체크포인트가 텍스트→이미지, 다중 참조 편집, 로컬 편집, 투명 RGBA 출력을 모두 커버한다. 연구·평가 목적으로 바로 배포 가능하며 Diffusers, ComfyUI, vLLM-Omni, SGLang, LightX2V의 0일차 지원에 포함됐다. 상용 배포는 Qwen과의 별도 라이선스가 필요하다.

전작 Qwen-Image는 2025년 8월에 20B 모델로 Apache 2.0 라이선스로 나왔고 편집은 별도의 Qwen-Image-Edit 체크포인트에 있었다. Qwen-Image-2.1은 두 작업을 한 모델로 묶으면서 크기는 약 1/3으로 줄었다. 참고로 7B 수치는 확산 트랜스포머만 해당되며, 파이프라인은 별도로 8B Qwen3-VL 인코더를 함께 로드한다.

아키텍처는 트랜스포머(32레이어 7B, 블록 인과 어텐션의 싱글스트림), 텍스트 인코더(Qwen3-VL 8B, 지시문과 조건 이미지를 하나의 표현으로 인코딩), VAE(64채널 RGBA 오토인코더, 16배 공간 압축과 네이티브 투명도), 스케줄러(Flow Matching, Euler 이산 스케줄링)의 4개 컴포넌트로 구성된다. 속도의 열쇠는 어텐션 마스크다. 텍스트 토큰에는 토큰 단위 인과 마스크, 이미지 토큰에는 이미지 내부 청크 단위 양방향 마스크를 쓰는 혼합 입상(mixed-granularity) 어텐션을 적용하고, 조건 접두부를 노이즈 잠재 앞에 배치해 각 디노이징 스텝에서 재사용한다. 텍스트와 입력 이미지는 첫 스텝에서 한 번만 계산하고 접두부 KV 캐시를 나머지 모든 스텝에 재활용해, 참조 이미지가 많아질수록 절감이 커진다.

기능 면에서는 텍스트에서 RGBA 이미지 생성, 투명 레이어 편집, 사진에서 피사체 추출이 가능하고, 최대 10장의 참조 이미지를 받는 다중 참조 편집(6인 단체사진 합성, 5장 기반 의상 예시 공개), 원·칠·마스크로 영역을 지정하는 로컬 편집과 인물·제품 신원 보존, 2048×2048 기본 최대 2752×1536 네이티브 2K 출력을 지원한다. 자체 벤치마크 Qwen-Image-Bench에서 60.28점으로 Nano Banana 2.0(59.82)과 모든 공개 모델을 앞섰으며, 비공개 6개 모델은 GPT Image 2.5 Sunburst(67.01)를 필두로 여전히 앞선다.

## 왜 중요한가?

생성과 편집을 한 모델로 합치면서 크기를 20B에서 7B로 줄인 것은 개인 GPU에서도 고급 이미지 AI를 돌릴 수 있게 된다는 뜻입니다. 투명 배경(RGBA) 출력과 다중 참조 편집은 상품 사진·디자인 실무에서 가장 요구되던 기능이라, 오픈웨이트 진영이 실무형 이미지 워크플로우를 흡수하는 흐름을 보여줍니다.

## 심층 분석

### 기술 의미
7B DiT + 8B VL 인코더 구성과 접두부 KV 캐시 재사용은 "멀티모달 인코더가 조건을 한 번 계산하고, 확산 본체가 재활용한다"는 효율 패턴의 정형화로 볼 수 있다(→ 분석). 혼합 입상 어텐션(텍스트는 인과, 이미지 청크는 양방향)은 조건 접두부를 불변 상태로 취급해 스텝 수에 비례하는 연산을 절감하는 설계로, 참조 이미지 수가 늘어나는 멀티레퍼런스 워크로우에서 특히 유리하다. 네이티브 RGBA VAE는 별도 매트팅 후처리 없이 투명도를 생성 과정 내부에서 다룬다는 점에서 파이프라인 단순화 효과가 있다(→ 분석).

### 업계 영향
Qwen-Image-Bench 점수는 자체 평가라 단정할 수 없지만, 공개 모델 최상위를 내세우며 FLUX 2 Max(32B)보다 작은 크기로 경쟁에 나선 것은 오픈웨이트 이미지 모델의 효율 경쟁이 과열됐음을 보여준다. 연구 라이선스(상용 별도 협의)는 Apache 2.0이었던 전작과 달라진 정책으로, 상용 사용자는 라이선스 확인이 필요하다. AMD ROCm과 FlagOS 8종 칩 지원, ComfyUI 네이티브 노드 탑재는 비엔비디아 생태계와 워크플로우 도구 진영의 즉시 채택이 이뤄지는 구조라 확산 속도가 빠를 것으로 예상된다(→ 분석).
