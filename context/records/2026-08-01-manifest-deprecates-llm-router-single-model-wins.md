# Manifest, LLM 라우터 폐지 선언 — "단일 모델 고수가 최선"

## 요약 (한국어)

LLM 게이트웨이 기업 Manifest가 7,000명의 클라우드 사용자 데이터를 바탕으로 **LLM 라우터를 폐지**했다고 발표했다. 3월에 출시된 라우터는 요청 복잡도(단순/표준/복잡/추론)에 따라 가장 비용 효율적인 모델로 자동 분류하는 기능이었다.

폐지 이유는 네 가지다: ① 프롬프트만으로는 작업 복잡도를 판단할 수 없다(도구 호출, 웹 검색 등 후행 컨텍스트 필요), ② 캐시가 라우팅보다 비용 절감에 더 효과적이다(75~90% 저렴), ③ 모델 간 전환은 동작 일관성을 깬다, ④ 예측 불가능성은 자동화 에이전트 워크플로에서 관리 비용을 증가시킨다.

## 심층 분석

Manifest의 라우터 폐지는 **에이전트 인프라 설계에 중요한 교훈**을 제공한다.

**라우팅 vs 캐시의 비용 절감 비교.** 업계가 모델 라우팅에 열광하는 동안, 실제 운영 데이터는 프리픽스 캐시가 더 큰 비용 절감 효과를 낸다는 것을 보여준다. 시스템 프롬프트와 대화 이력이 프롬프트의 대부분을 차지하는 에이전트 시스템에서 이는 특히 그렇다.

**에이전트 워크플로에서의 일관성 문제.** 에이전트가 다중 단계 작업을 수행할 때, 중간에 모델이 바뀌면 동작 패턴과 출력 품질이 달라질 수 있다. 이는 평가(evals)와 관측 가능성(observability)을 복잡하게 만들며, 에이전트 시스템의 신뢰성을 저하시킨다.

**작업 복잡도의 실시간 판단 불가.** "이 저장소의 테스트를 평가하라"는 요청이 HTML5 개인 사이트인지 Linux 커널인지에 따라 복잡도가 극적으로 달라진다. 이는 라우터가 효과적으로 작동하기 어려운 근본적 한계다.

업계 트렌드에 역행하는 대담한 결정이지만, 7천 사용자의 실데이터에 기반한 것이라 설득력이 있다.
